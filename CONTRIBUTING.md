# Contributing to `core-moteur`

`core-moteur` follows the Astrea-EIP engineering handbook for workflow, review, and release rules.

## Required references

Read these handbook sections before opening a pull request:

- `architecture/repositories`
- `contribution/git-workflow`
- `contribution/branches`
- `contribution/commits`
- `contribution/code-review`
- `workflows/auto-tag`

## Local rules

- Keep engine and domain logic scoped to this repository.
- Document any engine contract or behavior change in local docs.
- Keep pull requests focused on one issue.
- Run the local build and test flow before requesting review.
